# BeloTech

[![Deploy](https://github.com/BeloTechnologies/belotech/actions/workflows/deploy.yml/badge.svg)](https://github.com/BeloTechnologies/belotech/actions/workflows/deploy.yml)

Portfolio website for Belo Technologies, showcasing apps and projects.

**Live:** [belotech.net](https://www.belotech.net)

## Tech Stack

- React 19
- TypeScript
- Vite
- React Router
- Vitest
- Vercel

## Development

```bash
bun install
bun run dev
```

## Testing

```bash
bun run test
```
